## Live

Sketches that show off OllinLive features.

| Example | What it shows |
|---|---|
| [Parameters](Parameters/Sketch.swift) | tunable `@Param` knobs that become live inspector sliders under OllinLive |

Run one with `swift run Example-<Name>`, e.g. `swift run Example-Parameters`. Or run it under live reload: `swift run OllinLive Examples/Live/Parameters/Sketch.swift`.
