Linearly Transformed Cosines lookup tables
==========================================

`ltc_tables.bin` bundles the fitted lookup tables for area-light shading with
Linearly Transformed Cosines, from the reference implementation accompanying
the paper:

  Real-Time Polygonal-Light Shading with Linearly Transformed Cosines.
  Eric Heitz, Jonathan Dupuy, Stephen Hill and David Neubelt.
  ACM Transactions on Graphics (Proceedings of ACM SIGGRAPH 2016) 35(4), 2016.
  Project page: https://eheitzresearch.wordpress.com/415-2/

Provenance
----------

  Upstream:   https://github.com/selfshadow/ltc_code
  Commit:     31e5e96b54f98f33098f8503003119ba2231a1c6
  Fetched:    2026-08-02
  Source:     fit/results/ltc.js (the float32 export of the fit; the repo's
              .dds export of the same data is half-float, so the .js carries
              more precision)

Conversion: the two arrays in ltc.js (`g_ltc_1`, `g_ltc_2`, each 64x64 RGBA
float32, memory order index = roughnessColumn + angleRow * 64) were parsed and
written back-to-back as little-endian float32 with no reordering:
bytes 0..65535 are table 1, bytes 65536..131071 are table 2.

Table 1 holds the fitted inverse LTC matrix per (perceptual roughness,
sqrt(1 - cos(view angle))) texel, normalized by its middle element and stored
sparse (m00, m02, m20, m22). Table 2 holds (BRDF norm, average Schlick
Fresnel, unused, horizon-clipped sphere form factor).
