# The public surface, written down

One file per library product, one line per public declaration: the types with their conformances, then every member with its modifiers, labels, types, defaults, and deprecation, nested as the source nests them and sorted within each level. `Scripts/api-surface.sh` writes them from the build through the toolchain's `swift-api-digester` and, run without `--record`, fails when a listing and the build disagree. `Scripts/preflight.sh` runs that check whenever the framework changed.

The listings exist so that a change to the public API is a deliberate one. Add, rename, or remove something public and the check fails until `Scripts/api-surface.sh --record` rewrites the listing, at which point the diff under `API/` says exactly what changed, in review, beside the change that made it. Before 1.0 that is all the check asks. From 1.0 on, every public rename ships a deprecation shim, and a removed line here with no `@available(deprecated)` line beside it is the failure the shim rule exists to catch. The last naming sweep before that tag reads these files rather than the tree.

The listings are also read as a version. `Scripts/api-diff.sh` compares them with the ones at the last tag (or between any two refs with `--from` and `--to`) and reports every line added, removed, renamed, changed in signature, moved onto a protocol, or deprecated, pairing a removal with the addition it became when the same container holds one of the same name or the same shape. From that it names the bump the next release needs: at major zero any public change is a minor, and from 1.0 on a removal is a major, an addition or a deprecation a minor, and a release with no public change a patch. `--changelog` prints the skeleton of the changelog entry in its own "`old` is `new`" form, for a person to group and explain. The shim rule rides on the same diff: a spelling gone with no deprecated twin is counted before 1.0 and fails the run from 1.0 on (or under `--strict`), and in either era a shim in the working tree must sit in its module's `Deprecations.swift` and carry `renamed:` or `message:`. `Scripts/preflight.sh` runs its self-test and its summary on every framework or `API/` change.

The listings are generated. Do not edit them by hand; change the source and record. Their spelling follows the compiler that built the module, so they are recorded and checked on the development toolchain rather than on CI, whose Swift may lag.

The listings are also what the reference is measured against. `Scripts/check-api-pages.sh` reads every declaration here and asks whether any page under `Docs/` names it, in a code span, a fenced block, a heading, or a one-word bold run. It is the reverse of `Scripts/check-names.sh`, which reads a backtick in the prose back to the tree, and it is the direction nothing else covers: every other gate starts from the pages, so a public name no page mentions was invisible to all of them. A member a conformance requires, an operator, a subscript, an initializer the reference hands over another way, and the rest of the classes in its header are exempt by construction; anything else deliberately bare is listed with its reason in `Scripts/check-api-pages-allow.txt`, by name, by glob, or by the source file that declares it, which is how a whole tier that is public for another module (a wire protocol, the hosts' own inspector types) is excused in one line. An entry that matches nothing fails, and a name missing because the reference is a page short is never listed: the page is written.

The listings are also where the naming rules are held. `Scripts/check-api-names.sh` reads every line here against the rules the naming pass settled (limits are `min…`/`max…`, a public `seed:` is an `Int`, a resource loader spells `withExtension:`, a configuration Boolean reads as a third-person assertion, `advance(by:)` against `step(_:)`, and the rest of the list in its header) and fails on any name outside them, so a rule is checked on the surface every change records rather than read once in the last sweep before the tag. An exception is listed with its reason in `Scripts/check-api-names-allow.txt`; a name that is Ollin's own drift is renamed instead. `Scripts/preflight.sh` runs it every time, in under a second.
